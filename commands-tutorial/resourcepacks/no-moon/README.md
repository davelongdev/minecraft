# no-moon resource pack

Transparent copies of the sun (`celestial/sun.png`, added at Dave's request) and the eight moon-phase textures (`assets/minecraft/textures/environment/celestial/moon/*.png`, 26.3 paths) so the moon never shows; Dave didn't want players looking at it from the quest signs at dusk (time 12700). Resource pack format 97 (26.3). Build: `cd commands-tutorial/resourcepacks/no-moon && zip -r ../../../zips/no-moon.zip pack.mcmeta assets`. Client-side for now (Prism instance `resourcepacks/`, enable in Options > Resource Packs); on the studio server it becomes the server-sent pack.

Also (2026-10-18, Dave: dialog text blocky and blurry): `assets/tut/font/clean.json` = Liberation Sans TTF at size 10, oversample 4, unifont fallback (font id `tut:clean`, used by the quest dialogs via `gen_lessons.py` DIALOG_FONT — **without this pack those dialogs show missing-glyph boxes**), and `assets/minecraft/post_effect/blur.json` = vanilla's six blur passes plus two passes of `assets/tut/shaders/post/darken.fsh` (multiply by `Factor` 0.4 (was 0.55; Dave wanted darker), then a Factor-1.0 copy back), so menus blur as usual but the game behind them is darker (Dave 2026-10-18: blur back, and darker). Change the 0.4 to taste.
