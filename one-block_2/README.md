Steps for creating the world:

1. Allow Commands: ON
2. World Type: Superflat → Customize → Presets → The Void

That's it. Then drop zips/one-block.zip into the world's datapacks folder (or pick it via the Data Packs button at creation) and the pack sets up the rest itself on first load — clears the Void preset's little stone platform, places the sea lantern, freezes time to night.
