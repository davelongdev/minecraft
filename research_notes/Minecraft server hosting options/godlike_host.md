# GodLike Host (godlike.host) as a host for Minecraft Java 26.3 + server-side Fabric mods

Researched 2026-10-18. Scope: can GodLike host a small kids' program that needs several separate games running at once (several server instances or one plan split into several), each with custom server-side Fabric mods and datapacks, for roughly 10 to 20 players. All prices are as displayed on the dated fetch; GodLike's displayed prices mix first-month promos and list prices, so every figure below says which it is where the source made that clear.

Source-quality note up front: GodLike's own pages are JavaScript-heavy and the plan table did not fully render for a fetch, so per-tier list prices come partly from third-party review sites (undated or mid-2026). Trustpilot has pulled GodLike's score for a guidelines breach and says it removed fake reviews, so "4.8/5 Trustpilot" claims repeated on review sites are stale. No Reddit r/admincraft thread about GodLike could be retrieved at all.

## Who is GodLike: company, country, age, plans, prices, hardware, regions, pause/stop billing

### Takeaway
GodLike is Godlike Digital Solutions S.R.L., a Romanian company (Brasov) founded in 2021, billing in USD by default, selling shared Minecraft Java plans priced per GB of RAM (roughly $1/GB as a first-month promo, around $2.80 to $3.20/GB at list) on Ryzen 9 9950X3D / EPYC 9474F nodes in 12 regions including USA East and USA West. ## Minecraft 26.3 and Fabric support; uploading custom mod jars and datapacks; control panel

### Takeaway
Fabric is a one-click option in the panel's Version tab ("any version") and the panel has full SFTP plus a file manager, so custom mod jars and datapack zips can be uploaded; however no source confirms 26.3 specifically, and GodLike's Fabric guide is stale (its jar-naming rules stop at Java 17 while 26.1+ requires Java 25). The panel is GodLike's own "Godlike Game Panel"; the homepage calls it "Pterodactyl-style" but nowhere states it is Pterodactyl.

### Cited Findings

### Inferences
- Custom jars and datapack zips are uploadable: SFTP plus a file manager, and the Startup tab lets you point at any server jar. For a Fabric 26.3 server you'd install Fabric from the Version tab (or upload `fabric-server-launch.jar` and set it in Startup), drop mods into `mods/` and datapacks into `<world>/datapacks/` via SFTP, exactly as on a local server.

The KB's jar-naming scheme (`custom-java17.jar`) implies the panel selects the Java image from the jar name, and no `custom-java25` name is documented. Ask support in advance whether Java 25 images exist for 26.x before paying; the live chat reportedly answers within about 30 minutes.
- "Pterodactyl-style" plus Startup tab / allocations / sub-users strongly suggests a Pterodactyl fork or close derivative, but GodLike never says so; treat as unconfirmed.

## Multiple servers per account, cost per additional server, proxy networking, dedicated IP, ports

### Takeaway
GodLike's Server Splitter carves one paid plan into several independently managed sub-servers (each with its own RAM/disk slice and port allocations), which is the direct answer to "several games at once": buy one larger plan and split it, instead of buying several plans. Proxies are an advertised use case, but no Velocity/BungeeCord guide exists, split limits are undocumented, and dedicated IPs are only documented for VPS plans.

### Cited Findings
- Server Splitter marketing: "highly customizable server sharing tool lets you create an entire network from a single plan, so you don't need to buy several plans for a community network"; can create "additional Minecraft servers, proxy servers, and similar services from a single plan"; use cases include more modded servers for different gamemodes or a Discord bot — [About the panel (GodLike)](https://godlike.host/about-panel-en-old/); [search summary of GodLike splitter pages](https://godlike.host/split-server-en)
- Split-server KB procedure: open your server in the game panel, select "Server split", choose a server type (example: "Minecraft - Paper") and the RAM and disk to allocate, click "Split server", confirm "Yes, create subserver"; the new server "appears in your server list in the game panel and can be managed like your main server"; in the Server Split section you can change the main server, edit ports and "open new allocations (ports) with 'Change port'", change the server type, and edit RAM/storage; splitting "takes Storage and RAM from the main server" so leave enough for it; "the main server will be restarted when you split it"; servers list alphabetically, so name them "1. proxy", "2. lobby" to order them — [Split server (GodLike KB)](https://godlike.host/knowledgebase/split-server-en-db/)
- The same KB article does not state a minimum plan size, a maximum number of splits, or how to delete/merge a split back — [Split server (GodLike KB)](https://godlike.host/knowledgebase/split-server-en-db/)
- For scale: UltraServers' similar splitter is "available only on plans with 8GB or more" and allows "2 splits per plan" — this is a different provider and may not apply to GodLike — [UltraServers docs](https://docs.ultraservers.com/panel/server-splitter)
- Additional ports: homepage says GodLike "provides additional ports, allowing you to connect with other servers or services seamlessly" (count/price not stated) — [godlike.host](https://godlike.host/); panel page lists "Additional ports for your server" — [About the panel (GodLike)](https://godlike.host/about-panel-en-old/)
- Free `.godlike.club` subdomain per server, set in the panel's network settings so the server is reachable without a port number; DNS must be grey-clouded (not Cloudflare-proxied); the guide's example default address is `srv3.godlike.club:25566` (i.e. shared IP, non-default port) — [GodLike KB (Spanish) on subdomains](https://godlike.host/es/knowledgebase/how-to-use-own-domain-or-godlikes-subdomain-on-the-minecraft-server-es-db/)
- Dedicated IPv4: included in Game VPS plans (e.g. Mini VPS: 2 GB RAM, 1 dedicated vCPU at 3.4 GHz, 30 GB NVMe, 1000 GB traffic, one dedicated IPv4, IPv6; EUR 6.89/mo on a 3-month term, regular about EUR 8.61) — [WHTop Mini VPS listing](https://www.whtop.com/plans/godlike.host/152076); no price for a dedicated IP add-on on shared game servers was found in any source; the Terms list "extra IPs" among non-refundable items, implying they are sold as an add-on (Section 9.2) — [GodLike Terms](https://godlike.host/terms)
- No GodLike KB article on Velocity or BungeeCord was found; searches returned only other hosts' guides — [PaperMC Velocity FAQ (for reference)](https://docs.papermc.io/velocity/faq)
- Multiple separate plans on one account: no official statement found; general Pterodactyl-family panels list all of an account's servers in one dashboard (background only) — [Pterodactyl overview (Localtonet)](https://localtonet.com/blog/pterodactyl-game-panel)

### Inferences
- The cheapest way to run, say, four games at once is one plan sized for the sum (e.g. four Fabric servers at 2.5–3 GB each inside a 12 GB "Immortal" or a 16 GB plan) and three splits. Each sub-server gets its own port on the shared IP (`srvN.godlike.club:port`), its own console/files/backups, and can run a different jar. Kids would join each game by a different address or via a Velocity proxy that you run as another split.
- Whether a Velocity proxy with Fabric back-ends works is a configuration question, not a GodLike question: the splitter exposes extra port allocations, and Velocity's modern forwarding needs the FabricProxy-Lite mod on each back-end. Expect zero documentation help from GodLike for this.
- Buying several small plans instead of splitting is also possible (the panel lists multiple servers) but costs more per GB (the 2 GB Double is the worst per-GB tier) and loses nothing except the single-plan RAM ceiling.
- Datapack-only games (no mods) could alternatively share one Fabric server using multiple worlds via a world-management mod, but that collides with the per-world datapack and gamerule separation the program wants; separate sub-servers are the cleaner match.

### Gaps
- Maximum number of splits per plan and minimum plan size for splitting: not documented. Ask support.
- Whether split sub-servers can use the Version tab's one-click Fabric installer, or only manual jar upload: not documented (the KB example uses Paper).
- Dedicated IP price for a shared game server, and the number of free additional ports: not found.
- No Velocity/BungeeCord documentation from GodLike.

## 2026 reviews and reputation; outages and billing complaints; price comparison with Apex, Shockbyte, BisectHosting, Modrinth Servers

### Takeaway

### Inferences
- Per-GB at list for an 8 GB server: GodLike roughly $23–26 (estimated from the $2.80–3.20/GB tier pattern; actual Unstoppable price unconfirmed), BisectHosting $23.99, Apex $27.99, Shockbyte Premium $31.99, Modrinth Large $20 (quarterly) — GodLike is mid-pack, not a bargain, once promos end.
- For a multi-game program, GodLike's differentiator is the Server Splitter (one plan, several servers) rather than price; Modrinth Servers is cheaper and more Fabric-native but was out of stock at fetch time and has no split feature documented. Apex/Shockbyte/Bisect would require buying one plan per game.
- The removed-score Trustpilot status, the fake-review removal, and the billing complaint cluster together mean a teacher should treat GodLike as a workable but watch-your-card host; budget for a month-to-month trial with auto-renew turned off before committing a season.
