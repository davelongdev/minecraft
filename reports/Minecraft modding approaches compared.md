# Stay on data packs, add one key mod

*Research date 2026-10-12. Minecraft Java is on 26.3 (data pack format 121, Java 25); 26.4 is in snapshots. Sources are the five notes in `research_notes/Minecraft modding approaches/`. Two companion reports go deeper on the two main routes and this one stays consistent with them: [Minecraft Java mods in 2026](/home/dave/minecraft/reports/Minecraft%20Java%20mods%20in%202026.md) (loaders, toolchain, the thirty-line key mod) and [Minecraft datapack modding in 2026](/home/dave/minecraft/reports/Minecraft%20datapack%20modding%20in%202026.md) (the 26.3 format break, hard limits, tooling).*

**For a kids' program on Linux laptops running Java 26.3 through Prism, data packs plus chat commands stay the primary medium, and the one concrete wall you hit (the server can't see an arbitrary key such as N) is best solved by a thirty-line client-only Fabric mod that turns a key press into a `/trigger` command, not by moving anything into Java.** Java mods are the only route to client input, HUDs, and new block, item, or entity classes, but they cost JDK 25 plus Gradle, one rebuild per quarterly drop, and a loader on every seat, while one data pack zip already loads in both 26.2 and 26.3 and installs by copying into `saves/<world>/datapacks/`. Every other approach fails this program on at least one hard constraint: Minecraft Education and Bedrock add-ons (including Tynker) have no Linux client; Paper plugins, Skript, and Denizen need a dedicated server and never run in singleplayer; the classic Python and Scratch bridges (mcpi, RaspberryJuice, ScriptCraft, LearnToMod, arpruss's extension) are dead or frozen on 1.12-era Java; KubeJS and MCreator add a loader and a per-version jar to every laptop for mechanics a data pack already expresses; CC: Tweaked is the only scripting mod current on 26.3 and is a plausible later Lua step rather than a replacement. The teaching evidence points the same way: vendors place IDE-based Java at 10 and up with 13–17 as the main band, the one comparative study found blocks beat text on interest and perceived difficulty, and the concepts fifth-graders struggled with most (variables, conditionals) are exactly what `scoreboard players` and `execute if` make concrete. Mojang's 2025–2026 moves (deobfuscation, year-based versions, peer-to-peer "Online" worlds, a vague "creator platform") help mod authors and hosts but announce no Java add-on system, so the data pack ceiling (seven movement keys, statistics, clicks that land on something) is a planning assumption, not a bug to wait out. The recommendation is to prototype N with BindCommands in an hour, then write and own the tiny mod, ship it to kids as an exported Prism instance, keep the space-bar paging as the fallback so the tutorial never depends on the jar, and avoid Education, Bedrock, MCreator-as-curriculum, Paper for now, dialogs, Forge, Quilt, and CraftTweaker.

## Java mods buy the keyboard; data packs buy portability

The boundary between the two main routes is architectural. A data pack runs on the logical server, which "holds the authoritative world state" and the data packs, while the logical client handles rendering, input, and resource packs; even in singleplayer the two halves talk only through packets ([Fabric Wiki: Side](https://wiki.fabricmc.net/tutorial:side)). So a data pack can define content in roughly **55 registries** (functions, predicates, loot, recipes, enchantments, dimensions, world gen, dialogs, villager trades, world clocks, block transformers, GameTests, and more) and can see exactly what the server sees of a player: the seven `input` booleans (`forward`, `backward`, `left`, `right`, `jump`, `sneak`, `sprint`) added in 1.21.2, statistics such as `minecraft:jump` and `drop`, inventory NBT, and clicks that hit an entity or block ([Minecraft Wiki: Data pack](https://minecraft.wiki/w/Data_pack); [Minecraft Wiki: Predicate](https://minecraft.wiki/w/Predicate); [Minecraft Wiki: Statistics](https://minecraft.wiki/w/Statistics)). It can't add a block, item, or entity class, draw a GUI beyond dialogs, books, signs, and containers, or read a letter key; a 2025 feedback post asking for input detection notes command blocks "can't read movement directly", and the community's answers are client mods such as ControlCommands ([feedback.minecraft.net](https://feedback.minecraft.net/hc/en-us/community/posts/35962989701517-Add-player-input-detection-to-commands); [Modrinth: ControlCommands](https://modrinth.com/mod/controlcommands)). A mod is Java inside the game process on one or both sides, and Fabric's guide lists what that unlocks: items, blocks, fluids, entities, block entity renderers, custom screens and HUD elements, particles, key mappings, networking, and mixins that rewrite vanilla bytecode ([Fabric Developer Guides](https://docs.fabricmc.net/develop/)). Fabric's own sentence on the piece you need is blunt: "Key mappings only exist on the client side" ([Fabric Docs: Key Mappings](https://docs.fabricmc.net/develop/key-mappings)).

| Dimension | Java mod (Fabric or NeoForge) | Data pack (plus optional resource pack) |
|---|---|---|
| **Capability** | Whole game process: new block/item/entity classes, GUIs and HUD, keybinds, custom packets, mixins. Client-only, server-only, or both-sides depending on feature. | Server-side content and logic in ~55 registries plus mcfunction (macros, `/return`, `/random`, `/dialog`, 26.3 `/compute`). Sees seven movement keys, statistics, clicks on things. Visuals and sounds need a resource pack the client installs itself. |
| **Learning curve** | Java, JDK 25, Gradle 9, loader API; both loaders name "familiarity with Java" as a prerequisite. For a Python/C programmer, an afternoon to a day for the first build, mostly toolchain. Every tutorial older than 26.1 fails to compile. | JSON plus commands; chat is a REPL with Tab completion. Silent function load failures (check `latest.log`) are the main pain, fixed at edit time by Spyglass. 26.3 renamed half the loot/predicate format. |
| **Per-seat setup** | Fabric Loader plus Fabric API plus the jar in each instance's `mods/`; one jar per Minecraft version. Ship as an exported Prism instance `.zip`. | Zip in `saves/<world>/datapacks/`, then `/reload`. One zip spans 26.2 and 26.3 via `min_format`/`max_format`. Nothing else installed. |
| **Version churn** | Four drops a year, each pins the jar; 26.1 was a cliff (unobfuscated game, Java 25, every mod recompiled). 10–30 minutes per drop for a tiny mod, hours if a symbol moved. | Pack format bumps every drop (108→121 inside 26.3 alone); functions and scoreboards have not changed since 1.21, but 26.3 broke "nearly all complicated datapacks" that use predicate or loot JSON. |
| **Distribution** | Modrinth review currently two to four weeks; GitHub or USB plus Prism Import avoids it. Never runs on Realms. | Zip in the world. Runs on singleplayer, LAN, 26.2's P2P Online, Realms (whole-world upload only), and any server. Modrinth: 15,209 data packs, 2,306 tagged 26.3. |
| **Fit for teaching 8–14s** | Instructor plumbing only. Vendors start IDE Java at 10–12 ($1,099 in person at iD Tech) with 13–17 as the main band; no classroom study of Forge/Fabric with kids exists. | The medium itself. Checks are in-world outcomes, never keypress detection. Java's 99 commands include `/data`, `execute store`, and `/trigger`, which Bedrock lacks, so the variables→conditionals→functions→return→data ladder is Java-and-chat only. |

The churn row deserves emphasis because it is where the two routes diverge most for a volunteer instructor. Fabric's 26.1 post says "no mods from 1.21.11 or before will work without, at a minimum, recompilation", Yarn is gone, and Java 25 is the floor ([Fabric for Minecraft 26.1](https://fabricmc.net/2026/03/14/261.html)); 26.2 then relocated `Minecraft.screen` to `gui.screen()` and renamed `Gui` to `Hud` ([Balm 26.2 migration](https://balm.twelveiterations.com/migration/26.2)). BindCommands, the most-downloaded key-to-command mod, ships **one file per game version from 1.16.5 through 26.3** with `"minecraft": ">=26.3-"` in its manifest ([GitHub: bind-cmd fabric.mod.json](https://github.com/devs-immortal/bind-cmd/blob/HEAD/src/main/resources/fabric.mod.json)). Data packs churn differently: the format itself moves every drop, and 26.3 renamed `condition` to `type` in predicates and `conditions`/`functions` to `condition`/`modifier` in loot pools ([Minecraft Wiki: Predicate](https://minecraft.wiki/w/Predicate); [Nodecraft, 2026-09-15](https://nodecraft.com/blog/game-news-tips/minecraft-java-26-3-wilderness-bound-is-out-what-it-means-for-your-server)), but the wiki lists no function-format changes between 1.21 and 26.3 ([Minecraft Wiki: Function](https://minecraft.wiki/w/Function_(Java_Edition))), which is why this repo's four game packs carry `min_format: 107, max_format: 121` untouched. Mojang's direction amplifies the asymmetry: each drop lifts another hard-coded system into data (villager trades in 26.1; tool block conversion, fuels, compost, and sign text as item components in 26.3), which let Fabric delete `FuelRegistry`, `CompostingChanceRegistry`, and its brewing builders in the same release ([Fabric for Minecraft 26.3](https://fabricmc.net/2026/09/15/263.html); [Minecraft Wiki: Java Edition 26.3](https://minecraft.wiki/w/Java_Edition_26.3)). Every line of Java is a small recurring tax; every line of mcfunction is nearly free.

If you do write Java, Fabric is the loader for this job. On Modrinth, Fabric has **7,341 mods tagged 26.3 against NeoForge's 4,107 and Forge's 2,152** (queried 2026-10-12), Fabric API's first 26.3 build shipped the evening before the game did, and NeoForge took 75 beta builds over four weeks to drop its `-beta` tag ([Fabric API on Modrinth](https://modrinth.com/mod/fabric-api); [NeoForge maven-metadata](https://maven.neoforged.net/releases/net/neoforged/neoforge/maven-metadata.xml)). Quilt retired its own APIs in February 2026 because maintenance "has fallen largely on one developer" ([Quilt: non-obfuscated era](https://quiltmc.org/en/blog/2026-02-03-non-obfuscated-updates)). The mods report covers the toolchain, the key-mapping code, and the Prism Flatpak install path in detail; the short version is that the 26.3 client jar exposes `ClientPacketListener.sendCommand(String)`, so a client-only mod can send `trigger tut_key_n` exactly as if the kid had typed it, and the data pack reacts with a `trigger` objective and three lines in `player_tick`.

## Server plugins and scripting mods trade the compile cycle for a server or a loader

The survey below covers everything that is neither a Fabric/NeoForge mod nor a vanilla data pack. The pattern across all of it is that each approach removes one of the Java-mod costs (compiling, Java the language, a loader on every seat) by adding a different infrastructure requirement, and for a room of singleplayer Linux laptops most of those requirements are worse than the thing they replace.

Server plugins are the most capable "no mod on the client" route and the least compatible with this program's shape. Paper plugins are JVM code with lifecycle hooks, event listeners, registered commands, a tick scheduler, and the Adventure text library ([docs.papermc.io: How do plugins work](https://docs.papermc.io/paper/dev/how-do-plugins-work/)), and Paper has builds for every 26.x drop with "much of the API previously marked experimental" now stable in 26.3 ([papermc.io/news/26-3](https://papermc.io/news/26-3)). But Paper 26.x "requires at least Java 25", is a dedicated-server jar, and the docs never discuss client rendering or new registry content; a plugin can only reskin vanilla through resource packs and `custom_model_data` ([docs.papermc.io: Getting started](https://docs.papermc.io/paper/getting-started/)). There is no singleplayer plugin path, which means a Paper-based class is a server on the teacher's laptop plus every kid joining over LAN, and every kid's child account cleared for multiplayer in advance (more on that below). Skript removes the Java but not the server: it "requires Paper. Spigot is not supported", supports "the last 18 months of Minecraft versions", and its 1 September 2026 release 2.16.2 covers Paper 1.21.4 through 26.2 ([GitHub: SkriptLang/Skript](https://github.com/SkriptLang/Skript); [Hangar: Skript 2.16.2](https://hangar.papermc.io/SkriptLang/Skript/versions/2.16.2)). Denizen's 1.3.4 lists 26.3 and is built around the Citizens NPC plugin ([GitHub: DenizenScript/Denizen](https://github.com/DenizenScript/Denizen)), which is the one plugin-world feature with a direct tabletop mapping (NPC dialogue). Paper also dropped its internal remapper in 26.1 because "Mojang will stop providing obfuscated server jars", so pre-26.1 plugins that touched server internals break ([papermc.io/news/1-21-11](https://papermc.io/news/1-21-11)). Hold Paper in reserve for the day the program wants one shared persistent world with kid-made games in it; it's not a replacement for anything you do now.

Scripting mods split cleanly by 26.3 status. KubeJS lets you "write JavaScript scripts to customize a Minecraft modpack or server", including new blocks and items, but "Registry changes need a game restart", and while its `2601` branch was updated on 5 October 2026, the only builds seen are NeoForge 26.1.2 and 1.21.1 ([kubejs.com](https://kubejs.com/); [KubeJS branches](https://github.com/KubeJS-Mods/KubeJS/branches/all)). CraftTweaker has no 26.x branch at all ([CraftTweaker branches](https://github.com/CraftTweaker/CraftTweaker/branches/all)). CC: Tweaked is the exception worth noting: it "adds programmable computers, turtles and more" programmed in Lua, with turtles that move, place, break, and attack, peripherals such as monitors and speakers, and an `http` module, and its 1.120.3 release for 26.3 landed on 28 September 2026 ([tweaked.cc](https://tweaked.cc/); [CC: Tweaked releases](https://github.com/cc-tweaked/CC-Tweaked/releases)). Clubs have taught it to grades 1–2 (with "basic reading skills required") and grades 3–5 with class sizes capped at 8–12 ([Eventbrite listing](https://lsw19coding.eventbrite.com); [Jumbula listing](https://bc-arl-key.jumbula.com/Spring2025/CodinginMinecraft3rd5th)), though a parent-oriented review warns the curve is steep enough that "some kids will try it once and bounce off" ([ScreenWise](https://screenwiseapp.com/media/computercraft-game)). It is a mod, so it means Fabric on every laptop, and Lua turtles don't map onto board-game mechanics the way scoreboards and structures do; treat it as a possible third stage for kids who have outgrown commands, not as a replacement.

Mineflayer is in a different category: a bot framework, not a modding tool. It gives "a powerful, stable, and high level JavaScript API" for bots that join a server as a fake player, track entities, move with physics, dig, build, craft, and chat, supports 1.8 through 26.1, and released 4.39.0 on 6 September 2026 ([GitHub: PrismarineJS/mineflayer](https://github.com/PrismarineJS/mineflayer)). A bot can do only what a player could, so it never changes game rules, but it needs no install on the server. For a program that occasionally wants a scripted opponent or a "shopkeeper" that walks around, it is the live successor to the dead Python-over-socket stack: mcpi's last PyPI release was October 2021, RaspberryJuice's repo says it is "end of life", and ScriptCraft's last commit was 23 September 2017 ([PyPI: mcpi](https://pypi.org/project/mcpi/#history); [GitHub: zhuowei/RaspberryJuice](https://github.com/zhuowei/RaspberryJuice); [ScriptCraft commits](https://github.com/walterhiggins/ScriptCraft/commits/master)). The same rot took every Scratch-to-Minecraft bridge: arpruss's Scratch 3 extension needs Java 1.12.2 plus RaspberryJamMod, and FruitJuice, the RaspberryJuice successor, was last updated October 2024 and needs a websocket relay ([Instructables: Coding in Minecraft With Scratch](https://instructables.com/Coding-in-Minecraft-With-Scratch); [Hangar: FruitJuice](https://hangar.papermc.io/jdeast/FruitJuice)). The practical "bridge" for this program is conceptual: build the mechanic in Scratch (sprites, variables, broadcasts), then rebuild it with scoreboards, functions, and `execute`, naming the one-to-one mapping out loud.

## No-code makers, Bedrock, and Education all run somewhere other than a Linux Java laptop

MCreator is the only no-code mod maker still actively developed, and it's the one tool in this group that runs on Linux. It is GPL-3.0 software for "Minecraft Java Edition mods, Bedrock Edition add-ons, resource packs, and data packs" aimed partly at "educators, and STEM workshops", with Blockly-style procedures and an integrated code editor; releases run 2026.2.33518 ("Latest", 14 August 2026) to a 2026.3 EAP on 11 October, with Windows, Linux, and macOS builds, and its 2026.1 line pushed Bedrock add-on output hard ([GitHub: MCreator](https://github.com/MCreator/MCreator); [MCreator releases](https://github.com/MCreator/MCreator/releases); [mcreator.net/node/122081](https://mcreator.net/node/122081)). Camps use it for ages 10–15 and grades 3–5, and one listing notes Chromebooks and tablets "typically won't run" it ([CourseHorse listing](https://jbf.coursehorse.com/denver/classes/kids/kids-technology/kids-computer-programming/minecraft-modding-character-customizations); [Wayzata listing](https://wayzata.ce.eleyo.com/course/8994/youth-classes-fall-2024/intro-to-minecraft-modding)). The catch for this program is what comes out: a Java mod jar (needing Fabric or NeoForge in the instance, pinned to a Minecraft version) or a Bedrock add-on (useless here), and mcreator.net blocked automated fetches, so which Minecraft versions its 2026.2 generators target is unverified. MCreator is defensible as a one-off treat for a kid who wants a custom mob with a Blockbench model; as a curriculum it reintroduces every per-seat and per-version cost of Java mods without teaching the command grammar the rest of the program depends on. Blockbench, by contrast, is pure upside: free, GPL, Linux AppImage, release 5.2.2 on 8 October 2026 with Java block/item model export ([blockbench.net](https://www.blockbench.net/); [Blockbench releases](https://github.com/JannisX11/blockbench/releases)); it pairs with a resource pack for kids who want to draw their own tiles or key items. The rest of the 2014–2016 kid-modding generation is gone: LearnToMod's newest dated content is from 2016 with Google+ links in the footer ([learntomod.com](https://www.learntomod.com/)); Code Kingdoms still sells Java courses at $19.99/month for Windows or Mac with no stated Minecraft version ([codekingdoms.com](https://codekingdoms.com/)); Tynker is alive but its Minecraft tools target "Minecraft for Windows (Bedrock Edition)" and iPad ([tynker.com/minecraft/mods](https://www.tynker.com/minecraft/mods/)).

Bedrock add-ons are, in programmability, ahead of Java data packs and, for this program, irrelevant. Add-ons are "exclusive to Bedrock Edition": behavior packs (JSON), resource packs, and a JavaScript/TypeScript Scripting API whose `@minecraft/server` module (stable 2.10.0, beta 2.12.0 as of October 2026) registers custom commands, block and item components, dimensions, and world clocks ([minecraft.wiki/w/Add-on](https://minecraft.wiki/w/Add-on); [learn.microsoft.com: @minecraft/server](https://learn.microsoft.com/en-us/minecraft/creator/scriptapi/minecraft/server/minecraft-server?view=minecraft-bedrock-stable)). Microsoft's own comparison calls behavior packs "equivalent to Java's data packs" while noting "Java can create custom fonts and GLSL shaders, while Bedrock cannot. Bedrock can create custom particles and fogs, while Java cannot", and that Bedrock's command structure "is similar to the system used in versions of Java up to 1.13" ([learn.microsoft.com: Differences between Bedrock and Java](https://learn.microsoft.com/en-us/minecraft/creator/documents/differencesbetweenbedrockandjava)). Authoring officially assumes "a computer running Windows 10 or 11" ([learn.microsoft.com: Scripting intro](https://learn.microsoft.com/en-us/minecraft/creator/documents/scripting/introduction)), consoles can only get add-ons through the Marketplace or Realms, and selling on the Marketplace requires the Partner Program, whose applicants "must be a registered business" ([noxcrew.com](https://noxcrew.com/help/minecraft-marketplace-community-creators)). The teaching case against Bedrock is independent of platform: it lacks `/data`, `execute store`, NBT on `/give` and `/summon`, and `/trigger`, so the command ladder Command Forge climbs stops early there ([local report: Teaching Minecraft Java commands](/home/dave/minecraft/reports/Teaching%20Minecraft%20Java%20commands.md)). And no source found promises Java add-ons; the wiki's add-on page "contains no official Mojang statement about add-ons for Java Edition" ([minecraft.wiki/w/Add-on](https://minecraft.wiki/w/Add-on)).

Minecraft Education is the polished classroom product and it cannot run on your hardware. It is "an educational version of Bedrock Edition" with Code Builder, where students "write code in a code editor" and a programmable Agent executes it, plus Classroom Mode for the teacher; the platform list is Windows, macOS, ChromeOS, Android, iOS, and iPadOS, and the official system requirements say it is "not supported on any distribution of Linux" ([minecraft.wiki/w/Minecraft_Education](https://minecraft.wiki/w/Minecraft_Education); [edusupport System Requirements](https://edusupport.minecraft.net/hc/en-us/articles/360047556591)). Since the February 2026 update "MakeCode is now the only coding experience available" (Python Notebooks were removed), offering blocks, JavaScript, and Python ([edusupport: Changes To Code Builder](https://edusupport.minecraft.net/hc/en-us/articles/34761715494292-Changes-To-Code-Builder-Removing-Support-for-Python-Notebooks)). Licensing for a non-school program is a Commercial license: Microsoft's support article says "Any organization can purchase a Commercial license… (like a camp, club, after-school program, etc.)", and the FAQ puts it at **$36 per user per year** after a 2025-09-04 change, while the licensing page still shows $12 per user per year for camps and clubs; the academic rate of $5.04 is closed to non-institutions, though public libraries and museums are eligible ([edusupport article 360061371532](https://edusupport.minecraft.net/hc/en-us/articles/360061371532); [edusupport FAQ Commercial License Changes](https://edusupport.minecraft.net/hc/en-us/articles/38684236168980-FAQ-Commercial-License-Changes); [education.minecraft.net/licensing](https://education.minecraft.net/licensing)). It also needs a Microsoft 365 tenant with a unique account per student ([edusupport: Best Practices for Camps and Clubs](https://edusupport.minecraft.net/hc/en-us/articles/4416248488980-Best-Practices-for-Managing-Camps-and-Clubs)). Code Connection, the old bridge that put MakeCode on ordinary Bedrock, was removed from the Store in December 2023 ([MakeCode forum](https://forum.makecode.com/t/bedrock-edition-no-longer-working-with-makecode-super-disappointing/22597)). If Newburgh Creates ever partners with a library and gets Chromebooks or iPads, Education becomes a real option for the youngest kids; nothing built for Java transfers to it, and nothing built in it transfers back.

Client-only mods matter for hardware, not pedagogy. Sodium 0.9.2 for 26.3 shipped on 15 September 2026 with the note "Iris is not yet compatible", and a 26.3 Iris build appeared later from a single third-party listing; OptiFine's newest stable is HD U J9 for 1.21.11 (5 February 2026) with only previews for 26.x ([Sodium releases](https://github.com/CaffeineMC/sodium/releases); [optifine.net/downloads](https://optifine.net/downloads)). If the laptops stutter on 26.3, Sodium is the fix, and it rides in the same Fabric instance as the key mod. Finally, Mojang's own 2025–2026 moves change the hosting picture more than the modding one. Deobfuscation ("Modding is at the heart of Java Edition – and obfuscation makes modding harder") shipped with 26.1 and left the EULA unchanged ([Removing obfuscation in Java Edition](https://www.minecraft.net/en-us/article/removing-obfuscation-in-java-edition)); year-based versions arrived with 26.1 in March 2026 ([papermc.io/news/1-21-11](https://papermc.io/news/1-21-11)); 26.2 added a "Multiplayer Options" screen with "Invite to world" and a Friends List, described as "a first version" of peer-to-peer hosting ([minecraft.net: 26.2 Snapshot 7](https://minecraft.net/en-us/article/minecraft-26-2-snapshot-7)); and Minecraft LIVE in September 2026 produced only Jens Bergensten saying "they will begin an official creator platform" with no date, plus a coming "sound effects pack" resource pack type ([minecraft.wiki: LIVE Sept 2026](https://minecraft.wiki/w/Minecraft_Live_%E2%80%93_September_2026)). Vibrant Visuals remains Bedrock-first with Java "to follow" ([minecraft.net: Vibrant Visuals Java Edition](https://www.minecraft.net/en-us/article/vibrant-visuals-java-edition)). None of this is a Java add-on system or a first-party way to read a key; the P2P Online feature is the one item with classroom value, because it is the first vanilla channel other than LAN where a host's data pack runs for remote friends with no server to administer.

## The evidence puts IDE Java at 10+ and favours blocks, chat, and in-world checks

The commercial market has sorted itself by age, and it never puts an IDE in front of an eight-year-old. iD Tech's "Java Coding: Build Mods with Minecraft" is for **ages 10–12 at $1,099 in person or $429 virtual**, "Advanced Minecraft Modding with Java" is 13–17, and the virtual course has students "dig into the Minecraft source code" in IntelliJ ([iD Tech course](https://wwwapi.idtech.com/courses/java-coding-build-mods-with-minecraft); [iD Tech advanced course](https://www.idtech.com/courses/advanced-minecraft-modding-with-java)). Code.org's Minecraft Hour of Code marks its Education-based activities Grades 2–12 ([Code.org Minecraft Hour of Code](https://code.org/cs/hour-of-code/minecraft)); MCreator camps run grades 3–5 to ages 10–15; ComputerCraft runs from grade 1 with reading as the only prerequisite. The 2015 Forge-and-Eclipse workshops behind *Minecraft Modding with Forge* positioned Java modding explicitly as "kids' first experience of an IDE" ([SVCC 2015 session](https://www.siliconvalley-codecamp.com/session/2015/minecraft-modding-with-forge---part-1)), and nothing published since quantifies how that went. The only firsthand practitioner reports found are command-block classes: a summer game-design teacher had students play a finished command-block game first and then solve their own command-block problems collaboratively while the teacher "just sat back and listened" ([minecraft.net blog: Reflection on Minecraft Game Design Summer School Class](https://new.minecraft.net/en-us/blog/reflection-on-minecraft-game-design-summer-school-class)), and a fifth-grade teacher's plan was one command per command block with coordinates written on paper ([KQED](https://kqed.org/education/500238/how-minecraft-teaches-5th-graders-video-game-design)). That is the Command Forge model with less tooling.

The research base is thin but consistent. Kutay and Öner's six-week Minecraft coding program with 20 fifth-graders from a low-income school produced a significant gain in computational-concept knowledge, with sequences, events, and loops used correctly most often and **variables, operators, and conditionals least successfully**, while testing and debugging were frequent ([Boğaziçi archive](https://digitalarchive.library.bogazici.edu.tr/items/77989368-95d9-4851-8220-40f2886311d4/full)). Wu's small text-versus-blocks study in Minecraft Education (two classes of ten) found "block-based programming learning had greater benefit than text-based learning in learning interest and perceived programming difficulty" ([EdUHK repository](https://repository.eduhk.hk/en/publications/comparing-programming-interest-perceived-programming-difficulty-a/)). A 2026 quasi-experiment with 134 sixth-graders found Minecraft Education and Code.org blocks both raised computational-thinking self-efficacy with no difference between them ([Dergipark](https://dergipark.org.tr/en/pub/bited/article/1888031)). Read together, these say three things for this program: the medium matters less than the design, text should arrive with heavy scaffolding (which is what Command Forge's Tab-completion and Up-arrow quests do), and the concepts kids find hardest are precisely the ones `scoreboard players set`, `scoreboard players operation`, and `execute if score` make visible on a sidebar. No peer-reviewed study of commands or data packs as the teaching medium exists, so the "REPL immediacy" argument for chat commands is an inference from the general findings on debugging and perceived difficulty, not a measured result.

Per-seat logistics on Java are the quiet constraint on every multiplayer option. Java Edition is a one-time purchase of about $26.95 (from an aggregator; verify on minecraft.net) tied to a Microsoft account ([aggregator](https://school.acsrgmcnlr.edu.in/how-much-is-minecraft-java-edition.html)). For children under the regional threshold (13 in the US), a child account "cannot change its own privacy settings", only the family organizer who granted consent can, and **multiplayer is blocked by default until the organizer allows it on Xbox privacy settings**, with up to 24 hours before it takes effect and a launcher sign-out required ([Microsoft Q&A: Multiplayer Blocked (Child Account)](https://learn.microsoft.com/ru-ru/answers/questions/5912527/multiplayer-blocked-in-minecraft-java-edition-bugg); [Microsoft Q&A: how to enable multiplayer on java](https://learn.microsoft.com/en-us/answers/questions/3969481/how-to-enable-multiplayer-on-java); [Mud Club: Microsoft Accounts for Minecraft](https://mudclub.helpjuice.com/en_US/online-safety-and-privacy/understanding-microsoft-accounts-for-minecraft)). This is the single most common support failure a kids' club hits, and it applies to LAN, P2P Online, and servers alike; singleplayer worlds with a data pack avoid it entirely, which is a real argument for the current per-kid-island design. Prism's offline accounts require having logged in once with a Microsoft account that owns the game ([PrismLauncher-Unlocked README](https://slackbuilds.org/repository/15.0/games/PrismLauncher-Unlocked/)), so a shared program account can't be logged in on several laptops at once for multiplayer. On the mechanics the kids actually want, Java data packs cover each one natively and the repo already has a working example of most: dice via `/random value 1..6` into a scoreboard, turn order as a counter plus `execute if score`, character sheets as sidebar objectives, tiles as structures placed with `place template` (the `tile-game` WIP), dialogue via clickable chat, books, or `/dialog`, and parameterised functions via macros ([project CLAUDE.md](/home/dave/minecraft/CLAUDE.md)). Each is reachable as a typed chat command before any file exists, then promoted into a function, which is the Scratch-to-text progression the program is built around.

## Recommendation: keep the data packs, add the thirty-line mod, skip the rest

Keep Command Forge and the four games as pure data packs, and keep chat commands as what the kids learn. Nothing in the survey offers a better match for "8–14, Linux, Prism, singleplayer per kid, tabletop mechanics": the Java command grammar is the only one with the full variables-to-data ladder, the zip-in-world install is the only channel that works on every Java host, one zip already spans 26.2 and 26.3, and the per-kid singleplayer world sidesteps the child-account multiplayer gate that every shared-server option (Paper, Skript, Mineflayer, LAN) would force you to clear parent by parent. Adopt Spyglass for editing, because a red squiggle at edit time beats grepping `latest.log` for "Failed to load function", and consider Beet when `gen_lessons.py` grows another engine; the datapack report covers both. Keep the games on the stable subset (functions, scoreboards, structures, item components) so the `min_format`/`max_format` range stays honest, and put anything with predicate or loot JSON on a single target version.

Yes, the tiny client-only Fabric mod is worth adding, as instructor plumbing with a strict contract. Do it in two steps. First, spend an hour proving the data pack side with BindCommands: it has **613K downloads, files through 26.3**, and a key-to-command path that is entirely client side (its optional server half only pushes bindings to clients), so installing it plus Mod Menu and Fabric API in the Command Forge instance and binding N to `/trigger tut_key_n` tests the whole loop without writing Java ([Modrinth: BindCommands](https://modrinth.com/mod/bindcommands); [GitHub: devs-immortal/bind-cmd](https://github.com/devs-immortal/bind-cmd)). Second, write the purpose-built mod for class use: one class registering a `KeyMapping` for `InputConstants.KEY_N` and sending `trigger tut_key_n` from `ClientTickEvents.END_CLIENT_TICK` ([Fabric Docs: Key Mappings](https://docs.fabricmc.net/develop/key-mappings)), with `"environment": "client"` so it never matters on a server. Three third-party jars, a config GUI the kids can open, and someone else's porting cadence are worse than thirty lines you own, and the Fabric docs' `ScreenKeyboardEvents` hook would even let N advance quest text while the chat box is open, which space can't do. The contract is `trigger`: the server can't tell the mod's command from typing, so the pack works on vanilla, LAN, Online, and any server, and when the jar is absent N simply does nothing. Keep the jump-stat paging as the fallback so Command Forge never depends on the mod; that is what makes adopting it safe. Budget an afternoon for the first build and a short rebuild per drop, install by copying the jar into `~/.var/app/org.prismlauncher.PrismLauncher/data/PrismLauncher/instances/Command Forge/minecraft/mods/`, and hand kids an exported Prism instance `.zip` rather than publishing to Modrinth, whose review queue is "two to four weeks on average" ([Modrinth: Project Review Times](https://support.modrinth.com/en/articles/8793355); [Prism Wiki: Import](https://prismlauncher.org/wiki/help-pages/zip-import/)). If the laptops need it, Sodium rides in the same instance.

Two things are worth a later look rather than a decision now. CC: Tweaked is the only scripting mod current on 26.3 and the only one with a track record in kids' clubs; if a cohort of 12–14-year-olds outgrows commands and wants a real language, Lua turtles inside the same Fabric instance are a cheaper step than Gradle, and Lua is close enough to Python that you can teach it. And the 26.2 peer-to-peer Online feature deserves a quick check as a way for kids to play each other's games from home with no server, once their parents have cleared multiplayer. A Paper server with Denizen NPCs is the right tool if the program ever wants one persistent shared world; it is not the right tool for teaching commands to beginners on laptops.

Avoid the following, each for a concrete reason. Minecraft Education and anything Bedrock (Tynker, add-ons, the Scripting API): no Linux client, a $36-per-seat-per-year license or Windows hardware, a command dialect that stops at 1.13-era Java, and zero transfer to or from the data packs you already have. MCreator as a curriculum: it is alive and runs on Linux, but its output is a version-pinned mod jar that needs a loader on every seat, and it teaches Blockly procedures instead of the command grammar; keep it as a treat for one kid's custom mob. mcpi, RaspberryJuice, ScriptCraft, LearnToMod, and every Scratch bridge: dead or frozen on 1.12-era servers. CraftTweaker (no 26.x), KubeJS (no 26.3 build), Katton (26.1 only), Forge as a dev target (a third of Fabric's 26.3 catalogue and the big mods ship `neoforge`), and Quilt (APIs retired). Realms as a data pack channel: the only way in is uploading the whole world. Dialogs in the kids' UI: the permanent warning triangle offers to leave the world and controls are disabled while one is open ([Minecraft Wiki: Dialog](https://minecraft.wiki/w/Dialog)). Bundling the data pack inside a mod jar: possible on both loaders, but it moves the install from `datapacks/` to `mods/` and loses the one-zip-two-versions property. And Gradle in front of the kids: the research gives no evidence IDE modding outperforms commands at this age, and every vendor that sells it starts at 10–12 with a price tag that assumes a dedicated instructor per toolchain failure.

## Conclusion

The survey changes the framing from "mods or data packs" to a split by what each side of the game can perceive. Mojang is widening what a data pack can express every quarter (trades, tool actions, fuels, `/compute`) while leaving what it can perceive fixed at the protocol (seven keys, statistics, clicks on things), and nothing announced in 2025–2026 moves that line. So the sustainable architecture for a program with one experienced non-Java instructor is to spend mcfunction on everything game-shaped and spend Java only on perception and input, through a bridge so small that each quarterly rebuild is a chore rather than a project. The `trigger` command is the hinge: it is the one place where client-side code and server-side data meet on terms a vanilla server already understands.

The other routes are not wrong so much as aimed at other rooms. Education Edition and Bedrock add-ons are built for Chromebook and console classrooms; Paper and Skript for people running a shared server; MCreator for a kid who wants a mob more than a mechanic; CC: Tweaked for the one who wants a language. Knowing which room each belongs to is what lets this program say no to them without second-guessing, and it leaves a short list of quick checks before the next class: BindCommands in the Command Forge instance, Spyglass under nvim, and whether a 26.2 Online world lets two kids play one another's game from home.
